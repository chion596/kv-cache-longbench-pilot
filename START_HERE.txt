Для воспроизведения завершённой серии:
1. На login-узле: git pull --ff-only, module load python, conda activate kvcache.
2. Проверить существующий Qwen3-4B n80, архив и локальные веса.
3. Подготовить native-chat входы для трёх моделей, не меняя старые каталоги.
4. Отправить только smoke: sbatch --export=ALL,PHASE=smoke slurm/protocol.sbatch.
5. Проверить Slurm, model.generate parity, Dynamic split parity и реальные ответы.
6. При успешных проверках отправить full; анализ — src.score_protocol.
