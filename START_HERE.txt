KV CACHE + LONGBENCH: БЫСТРЫЙ СТАРТ
====================================

Репозиторий ПУБЛИЧНЫЙ. Это отдельный проект, продолжение предыдущего
исследования Qwen3 KV Cache. GPU-эксперименты пока не выполнялись.

Главная инструкция с командами:
  docs/cluster_first_run.md

ПОРЯДОК РАБОТЫ:
1. На Mac: git pull --ff-only origin main
2. Подключись к login-узлу кластера ВШЭ через ранее рабочий SSH.
3. На login-узле: клонируй этот репозиторий.
4. Активируй уже существующее conda-окружение kvcache.
5. Убедись, что локальные веса Qwen3-1.7B доступны по MODEL_PATH.
6. Скачай официальный LongBench и подготовь тестовую выборку.
7. Проверь unit tests и запусти ТОЛЬКО Slurm smoke.
8. Принеси результаты smoke на проверку, прежде чем запускать 9 jobs.

Важно: не коммить скачанные датасеты, веса моделей, секреты или токены.
Не запускай скрипты GPU прямо на login-узле.

Подробнее: docs/cluster_first_run.md
